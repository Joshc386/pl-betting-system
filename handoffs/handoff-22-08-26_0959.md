## Lessons that cost time this session — worth not re-learning

- **Source-introspection tests: match line-wise, never by substring.** Twice in two days
  an assertion was vacuous because the callee's name is a substring of the caller's
  (`_weekly_retrain()` inside `def job_weekly_retrain()`). Both were caught only by
  deliberately reintroducing the bug.
- **Mutation-check every regression test.** Three separate tests this session passed
  against the very defect they were written for until the frame or the assertion was
  corrected.
- **Split a branch into commits by dependency, not by theme.** Grouping by theme
  produced a commit that would have raised `AttributeError` — `championship_predict.py`
  calls `dc.seed_arrivals()` and `model.py` was in a different commit. Caught before
  pushing; fixed with `git reset --mixed` on unpushed work.
- **Read pytest's real output, not the exit code, when piping.** `| tail` returns
  *tail's* status; a failing suite reported exit 0.
- **Never `grep -r` from the project root** (OneDrive; times out). Use the Grep tool.
- `PYTHONIOENCODING=utf-8` is needed for anything printing `✓`.
