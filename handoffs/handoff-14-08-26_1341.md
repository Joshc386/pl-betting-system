## Gotchas discovered this session

- **A 200 is not proof you got the file you asked for.** Apache `mod_speling` silently substitutes the nearest filename. This is the third member of a family the chain keeps hitting — see "the pattern" below.
- **`requests` guesses ISO-8859-1 when the server sends no charset** (RFC 2616), so `resp.text` renders a UTF-8 BOM as `ï»¿` and names the first column `ï»¿Div`. Parse `resp.content`, not `resp.text`. The download path had been mojibaking accented names this way for as long as it existed, while the cache path decoded them correctly — the same season could differ depending on cache state.
- **A mock more polite than the real server passes tests that the real server fails.** All five division-guard tests were green while the guard rejected *every* real season. The rule that fell out: model the transport faithfully (bytes, charset, redirects) and let the payload be synthetic. `_FakeResponse` in `tests/test_canonical_builder.py` now does this deliberately.
- **`utf-8-sig` is stricter than `utf-8` in pandas.** `E0_0405.csv` parsed under `utf-8` and failed under `utf-8-sig` (latin-1 nbsp, `0xa0`). Needs `encoding_errors="replace"`. `E1_0405.csv` had been failing this way *before* this session; all 52 cached raws now parse, where two did not.
- **`SQUAD_FEATURES` reach no model** — 0/16 in `ou_features`/`btts_features` for both leagues. The previous memory claimed otherwise and has been corrected. Not an oversight: they are NaN for every training season before 24, which is precisely what the adjuster existed to work around.
- **`grep -r` from the project root times out on OneDrive.** Hit four times this session despite two previous handoffs warning about it. Also applies to Python `glob.glob(..., recursive=True)` and `find .`. **Use the Grep tool with a `glob` filter.**
- Python console output still dies on cp1252 for `→`/`—`; the ingest log shows the mojibake. Use `PYTHONIOENCODING=utf-8`.
- Full suite is now **~10-18 minutes** (varies). Run it in the background, and **re-run it if you edit after launching** — two runs were wasted this session by not doing so.

## The pattern worth carrying forward

Every problem found today was **a failure that looked like success**:

| Failure | Looked like |
|---|---|
| 301 → `EC.csv` | HTTP 200 with well-formed rows |
| Test suite green | guard rejecting all four real seasons |
| Missed scheduled job | `LastTaskResult: 0` |
| Squad adjuster retraining weekly | a job that ran and wrote a file |

None surfaced as an error. Each needed something to *assert* the expected thing was true — which is what the Freshness Gate does for staleness and what `_serves_division` now does for provenance. **ADR 0006's amendment names the next gap in the same family: nothing asserts "the ingest ran today."** The gate catches the consequence two days later, which is a downstream symptom, not an alarm.
