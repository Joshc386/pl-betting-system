## Gotchas discovered this session

- **`git apply --unidiff-zero` positions hunks by line number, not content.** A subset of a `-U0` diff carries new-side numbers that go stale the moment earlier hunks are dropped, and git places content by them — this produced a syntactically broken intermediate commit. Generate with context (`-U3`), or build the intermediate file from the original's own line numbers. Either way: **a clean final tree says nothing about intermediate commits.** Compile or test each one, or `git bisect` inherits a commit that was never valid.
- **The Bash tool is Git Bash, not PowerShell.** `@'...'@` here-strings silently corrupt the commit subject. Use a heredoc.
- **`reports/` is gitignored.** Anything meant to outlive the session belongs elsewhere — `docs/adr0007_baseline.md` was moved for this reason.
- **A guard shaped around the first change you make will have a blind side on the second.** `PENDING_NEW_COLUMNS` handled additions and looked complete; the first removal failed the suite for the wrong reason.
- **Concurrent pytest runs race on the raw cache.** Both write `E0_0405.csv`, which cannot be read back as UTF-8 and re-downloads every build.
- The full suite takes **6–18 minutes** depending on cache warmth. Run it in the background.
