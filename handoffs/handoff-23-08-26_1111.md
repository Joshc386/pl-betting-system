## The through-line, still holding

Last block named it: **a check or derivation validated against a state the rollover
then left behind.** Every defect found this session was that shape again — including
the two P0s, which were *inside the commit written to apply that lesson*.

The specific rule both call sites got wrong, and worth adding to ADR 0011:

> **Arrival selects the route. It never selects the duration.**

`division_movement.arrivals_for` documents arrival as season-long membership —
"never 'has no rows yet', which is a statement about the calendar rather than about
the side". Correct for choosing *which cohort* seeds a side. Both predictors then used
it to decide *how long* the seed applies, which it cannot answer. Two call sites got
this wrong; a third will.

## Lessons that cost time this session

- **A red phase can be invalid.** A synthetic fixture had already been played, so
  `_fixture_feature_row` returned it from its exact-fixture shortcut and no seeding
  code ran. Five tests "failed" and two passed vacuously. Caught only because the
  failure *direction* was wrong, not the count. There is now a guard test asserting the
  fixture under test is unplayed.
- **Mutation-check the mutation.** One mutation put a double-quoted SQL literal inside
  a double-quoted Python string and produced a `SyntaxError` rather than a behaviour
  change — that proves nothing about the test. Two others caught nothing because the
  tests only exercised one league.
- **A test that fails for the wrong reason is one edit away from passing for the wrong
  reason.** Three tests this session failed against *correct* code because the callee
  had moved into a private body.
- **Verify agent findings before reporting them.** Of seven CRITICAL claims, two were
  confirmed verbatim, three were materially different from the claim, and the review's
  own proposed no-harm gate turned out to be unable to measure the fix at all —
  backtests replay pipeline rows and never call the serving path.
- **Never `grep -r` from the project root.** OneDrive; it times out. Cost one wasted
  background task this session. Use the Grep tool.
- **Read `PYTEST_EXIT` from the file, not the tool's exit code**, when the command ends
  in `tail` or `grep`.
