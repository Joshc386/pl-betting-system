## Gotchas discovered this session

- **`.bat` files must be CRLF.** An LF-only `.bat` makes `cmd.exe` open an interactive prompt instead of executing. `weekly_retrain.bat` is CRLF; `monthly_betfair_update.bat` is LF and works, so it's inconsistent — prefer CRLF.
- **Git Bash mangles `cmd.exe /c`** via MSYS path conversion (`/c` → `C:\`). Use the PowerShell tool to invoke `.bat` files, not Bash.
- **`Set-ScheduledTask -Settings` replaces the whole settings object** — it will silently drop `StartWhenAvailable` unless re-specified. Always re-verify after changing a task.
- **Backup-before-overwrite got expensive once scheduled.** Daily runs meant ~2.9 GB/year per league, all syncing to OneDrive. Now pruned to newest 5 (`KEEP_BACKUPS`).
- **`normalize()` falls back to substring matching** (`api/team_mapping.py:94-98`), so a missing alias fails *silently* rather than raising. Bradford City was the only gap in 46 names — added — but the fallback remains a latent sharp edge.
- **Console is not UTF-8** — keep log strings ASCII in anything Task Scheduler runs.
