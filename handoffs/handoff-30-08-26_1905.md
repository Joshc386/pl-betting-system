## The through-line, now at four instances

Previous blocks named it: **a check or derivation validated against a state the
rollover then left behind.** ADR 0011 sharpened it to *"arrival selects the
route; it never selects the duration"*. This session found the same shape twice
more, both live:

1. **Rolling features are computed with `groupby("team")`** — no season or gap
   awareness, `min_periods=1`. Ipswich's PL seasons are `[0, 1, 24]`, so the
   `CR_20` training kept for their first match of season 24 was a rolling mean
   over their 2000/01 and 2001/02 matches. Twenty-three years stale.
2. **The Dixon-Coles seed gate counted *total* appearances** while the feature
   row counted *per venue* — and the comment above both call sites asserted
   they "can never disagree". They disagreed for every arrival between roughly
   match four and match ten.

Both are the same blind spot as `_decay_weights`: **sequence position standing
in for calendar time.** That is now the single most reliable place to look for
the next defect in this system.

## Lessons that cost time this session

- **Ask seeding questions of the pipeline output, never the canonical CSV.**
  `initialize_promoted_features` runs inside `run_pipeline`, so the CSV on disk
  is pre-initialisation. A first attempt at the divergence check read the CSV
  and appeared to *disprove* the divergence. Cost one wrong answer reported to
  the user and retracted.
- **Background tasks lose piped stdout here.** A command ending in `| tail`
  returns exit 0 and empty output. Redirect to a file and read the file. This
  is the fuller form of the previous block's `PYTEST_EXIT` lesson.
- **`$TMPDIR` is not set in Git Bash.** Spell the scratchpad path out.
- **A test can be vacuous in more than one way, and both look like a pass.**
  Writing one behavioural test produced two: a frame where cohort and actual
  carried the same value so no weight could move anything, then a frame where
  the arrival was present in both seasons — which the PL detects via
  `Home_Promoted` and the EFL does not detect at all, since it reads a season
  difference. **A frame that satisfies one pipeline tests one pipeline.**
- **Check the date from the clock, not from the last handoff's filename.** ADR
  0012 shipped dated 2026-08-23 and had to be corrected to 2026-08-30.
- **Scope a measurement to the rows the change can actually move.** Arm 4 over
  the whole seed slice would have diluted a real effect toward zero; scoped to
  the 705 rows where the two gates disagree, it separated cleanly.
