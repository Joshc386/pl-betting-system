A systematic approach to betting on 3 different markets for EFL and PL games.
This is a semi-automated bot that aims to suggest bets with the highest edge based on the probability calculated versus what the bookmakers are offering.
Data is ingested, cleaned/processed and then fed into a Dixon-Coles model which looks at the data, looks at the relevant fixture and then outputs a probability. This is then compared to the bookmakers and then I decide whether to place the bet or not.
